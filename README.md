# DevOps Task Platform

A practical portfolio project demonstrating application development and
DevOps practices using Python, FastAPI, Docker, PostgreSQL, CI/CD,
monitoring, Kubernetes and GitOps.

## Project goals

- Build and test a REST API.
- Package the application with Docker.
- Run application services using Docker Compose.
- Persist application data in PostgreSQL.
- Automate testing and image builds with CI/CD.
- Add observability, security and deployment automation.
